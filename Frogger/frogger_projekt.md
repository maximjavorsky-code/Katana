# Frogger

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou arkádovou hru Frogger v jazyce Python.
Hráč ovládá žábu a snaží se dostat přes silnici plnou aut na druhou stranu.

Hra je určena pro začátečníky jako ukázka práce s knihovnou pygame.

## Funkcionalita programu
- Ovládání hráče pomocí klávesnice (šipky)
- Pohybující se překážky (auta)
- Kolize (prohra při nárazu)
- Restart hry

## Technická část
- Jazyk: Python
- Knihovna: pygame
- Herní smyčka (game loop)
- Detekce kolizí pomocí obdélníků (Rect)
- Použití seznamů pro ukládání objektů (auta)
