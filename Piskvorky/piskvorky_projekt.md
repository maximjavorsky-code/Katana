# Piškvorky (Tic-Tac-Toe)

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou konzolovou hru Piškvorky pro dva hráče.
Hra umožňuje střídání tahů, kontrolu vítězství a detekci remízy.

## Funkcionalita programu
- Vykreslení herního pole (3x3)
- Zadávání tahů hráči
- Kontrola platnosti vstupu
- Vyhodnocení výhry nebo remízy
- Střídání hráčů (X a O)

## Technická část
- Jazyk: Python
- Použité prvky:
  - seznam (list) pro uložení hracího pole
  - funkce pro kontrolu výhry
  - cyklus while pro běh hry
- Algoritmus:
  - po každém tahu se kontrolují všechny možné výherní kombinace
