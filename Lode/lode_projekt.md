# Lodě

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou textovou hru Lodě (Battleship) v jazyce Python.
Hra je určena pro jednoho hráče proti počítači.

## Funkcionalita programu
- Generování herního pole
- Náhodné rozmístění lodí počítačem
- Zadávání střel hráčem
- Vyhodnocení zásahů a minutí
- Ukončení hry při potopení všech lodí

## Technická část
- Jazyk: Python
- Použité struktury:
  - 2D pole (list listů)
- Algoritmy:
  - Náhodné rozmístění lodí
  - Kontrola kolizí při pokládání lodí
- Knihovny:
  - random
