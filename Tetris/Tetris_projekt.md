# Tetris hra

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou arkádovou hru Tetris v jazyce Python.
Hráč skládá padající bloky tak, aby vytvářel celé řádky, které následně mizí.
Projekt je určen pro začátečníky, kteří se učí práci s grafikou a herní logikou.

## Funkcionalita programu
- generování tetris bloků (tetromino)
- pohyb bloků (doleva, doprava, dolů, rotace)
- detekce kolize
- mazání plných řádků
- počítání skóre
- konec hry

## Technická část
- jazyk: Python
- knihovna: pygame
- algoritmy:
  - mřížkový systém (2D pole)
  - kontrola kolizí
  - rotace tvarů
- datové struktury:
  - seznamy (grid, tvary bloků)
