# Parkour hra

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou 2D parkour hru v Pythonu.
Hráč ovládá postavu, která skáče po platformách a snaží se nespadnout.

Hra je určena pro začátečníky, kteří se chtějí naučit práci s knihovnou pygame.

## Funkcionalita programu
- Pohyb hráče doleva a doprava
- Skákání (parkour mechanika)
- Kolize s platformami
- Gravitace
- Restart hry při pádu

## Technická část
Použité technologie:
- Python
- knihovna pygame

Použité principy:
- Herní smyčka (game loop)
- Kolizní detekce
- Objektový přístup (Player, Platform)
- Základní fyzika (gravitace, skok)

Struktura:
- main.py obsahuje celý herní kód
