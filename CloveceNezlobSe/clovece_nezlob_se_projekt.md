# Člověče, nezlob se (CLI)

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou textovou verzi deskové hry Člověče, nezlob se v jazyce Python. 
Hra je určena pro 2–4 hráče a běží v terminálu.

## Funkcionalita programu
- Hod kostkou
- Pohyb figurek
- Nasazení figurky při hození 6
- Kontrola výhry
- Střídání hráčů

## Technická část
- Jazyk: Python
- Knihovny: random
- OOP přístup (třídy Player a Game)
- Herní logika implementována pomocí cyklů a podmínek
- Vlastní datová struktura: seznam pozic figurek
