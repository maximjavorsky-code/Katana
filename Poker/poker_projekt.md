# Poker hra

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou textovou pokerovou hru v jazyce Python.
Hra je určena pro jednoho hráče proti počítači.

## Funkcionalita programu
- generování balíčku karet
- míchání karet
- rozdání karet hráči a AI
- vyhodnocení kombinace
- určení vítěze

## Technická část
- jazyk: Python
- knihovny: random
- datové struktury: list, tuple
- algoritmy: náhodné míchání, jednoduché porovnání kombinací
