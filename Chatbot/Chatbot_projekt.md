# 🤖 Projekt: Chatbot

## 📌 Popis
Tento program představuje jednoduchého chatbota, který komunikuje s uživatelem pomocí textu v konzoli.

Chatbot reaguje na základě předem definovaných klíčových slov a odpovědí.

## 🎮 Funkčnost
- Uživatel zadává zprávy
- Program vyhledá klíčové slovo
- Vrátí náhodnou odpověď
- Pokud nerozumí, odpoví univerzálně
- Program se ukončí při zadání "konec"

## 🧠 Funkce programu

### `ziskej_odpoved(vstup)`
- Přijímá text od uživatele
- Hledá klíčová slova
- Vrací odpověď

### `main()`
- Řídí komunikaci s uživatelem
- Zajišťuje běh programu

python Chatbot.py
