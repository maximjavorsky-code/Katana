# TurnBattle

## Popis a cíl projektu
Jedná se o jednoduchou 2D tahovou hru, ve které hráč bojuje proti nepříteli.
Hra je určena pro procvičení základních principů programování, jako jsou
třídy, funkce, podmínky a cykly.

## Funkcionalita programu
- Tahový systém (hráč vs nepřítel)
- Možnost útoku a léčení
- Náhodné chování nepřítele
- Výpis stavu hráče a nepřítele

## Technická část
Program je napsán v jazyce Python.

Použité prvky:
- Objektově orientované programování (třídy Player, Enemy)
- Smyčky (while pro běh hry)
- Podmínky (if/else pro rozhodování)
- Modul random pro náhodné akce nepřítele

Struktura:
- main.py: spuštění hry
- game.py: herní logika
- player.py: třída hráče
- enemy.py: třída nepřítele
