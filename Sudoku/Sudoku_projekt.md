# Sudoku

## Popis a cíl projektu
Cílem projektu je vytvořit konzolovou aplikaci pro hraní hry Sudoku.
Uživatel vyplňuje čísla do mřížky 9x9 tak, aby splňovala pravidla hry.
Projekt je určen pro procvičení práce s poli, funkcemi a algoritmy.

## Funkcionalita programu
- Zobrazení herního pole
- Zadávání hodnot uživatelem
- Kontrola správnosti tahu
- Kontrola dokončení hry
- Možnost ukončení hry

## Technická část
- Programovací jazyk: Python
- Datová struktura: 2D pole (list of lists)
- Algoritmus pro kontrolu pravidel Sudoku:
  - kontrola řádku
  - kontrola sloupce
  - kontrola 3x3 bloku
- Vstup uživatele přes konzoli
