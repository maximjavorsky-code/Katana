# Pac-Man hra

## Popis a cíl projektu
Cílem projektu je vytvořit jednoduchou arkádovou hru Pac-Man.
Hráč ovládá postavičku, sbírá body a vyhýbá se nepřátelům.

## Funkcionalita programu
- Pohyb hráče pomocí klávesnice
- Sběr bodů
- Jednoduchý nepřítel (ghost)
- Kolize hráče s nepřítelem
- Herní smyčka

## Technická část
- Programovací jazyk: Python
- Knihovna: pygame
- Herní smyčka (game loop)
- Detekce kolizí (rect collision)
- Jednoduchá AI nepřítele (náhodný pohyb)
